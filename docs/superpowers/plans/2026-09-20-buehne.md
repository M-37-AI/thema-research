# Bühne – Implementierungsplan

> Stand 2026-09-20: umgesetzt (Commits „Bühne: …“). Abweichungen vom Plan: SSE-Ereignis heißt `karte` statt `agent`; Fertigmeldung wird schon durch das Tool-Ergebnis von `TaskUpdate` aufgelöst (funktioniert auch ohne Gate-Log); Verbrauch wird je `message.id` einmal gezählt; Phase beachtet Datei-Änderungszeiten (Replay); `?standbild=1`.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Ein lokales Browser-Fenster, das während eines `/thema`-Laufs live ein Raster von Agenten-Karten mit Strom, Zustand, Türsteher-Entscheidungen und Kosten zeigt, plus Replay aus den Transkripten.

**Architecture:** Reine Lese-Anwendung. `tools/buehne_modell.py` wandelt Transkriptzeilen und Gate-Log-Zeilen deterministisch in Ereignisse und Kartenzustände (testbar, ohne I/O). `tools/buehne.py` tailt die Dateien in Threads, hält einen Zustand unter einem Lock und pusht per Server-Sent Events an `templates/buehne.html`, eine framework-freie Seite.

**Tech Stack:** Python 3.11 Standardbibliothek (`http.server`, `threading`, `json`), pytest; HTML/CSS/JS ohne Abhängigkeiten.

**Spec:** `docs/superpowers/specs/2026-09-20-buehne-design.md`

## Global Constraints

- Nur Standardbibliothek in `tools/buehne*.py`; keine neuen Einträge in `requirements.txt`.
- Server lauscht ausschließlich auf `127.0.0.1`, Standardport 8767.
- Deutsche Meldungen, Dateinamen und JSON-Schlüssel ohne Umlaute, jedes Tool hat `--help` (Konvention aus CLAUDE.md und `tools/gemeinsam.py`).
- Die Bühne schreibt nichts in `runs/`, `data/` oder `~/.claude/`.
- Tests laufen offline: `python3 -m pytest tests/ -q` (Teil von `bash tests/run_all.sh`).
- Preise in `tools/preise.json`: fable-5-1 10/50/0.25/12.5/20, opus-5 5/25/0.5/6.25/10, sonnet-5 2/10/0.2/2.5/4, haiku-4-5 1/5/0.1/1.25/2 (USD je Mio Tokens: input/output/cache_lesen/cache_schreiben_5m/cache_schreiben_1h).
